## Featured Projects

### 🧠 [recognition-system](https://github.com/moeezmalik10/recognition-system)
A from-scratch face recognition system built on a **NumPy-only multilayer perceptron** — no PyTorch, no TensorFlow, just linear algebra and hand-implemented gradient descent.
`Python` `NumPy` `Jupyter Notebook`

### 🏥 [Alzheimer-s-Disease-Detection-using-MRI-Images](https://github.com/moeezmalik10/Alzheimer-s-Disease-Detection-using-MRI-Images)
Classifies Alzheimer's disease stages from brain MRI scans using a fine-tuned **ResNet-18**, later extended with Grad-CAM explainability research.
`Python` `ResNet-18` `Jupyter Notebook`

### 🗺️ [the-living-archive](https://github.com/moeezmalik10/the-living-archive)
A platform for documenting urban exploration — log, tag, and share discoveries from abandoned places and hidden spots. [Live →](https://the-living-archive-neon.vercel.app)
`TypeScript`

### 🧭 [directionwise](https://github.com/moeezmalik10/directionwise)
A career-counselling tool that helps students explore paths and make informed decisions. [Live →](https://directionwise-jx2y43b9mxn9rtbnhgmqcw.streamlit.app/)
`Python` `Streamlit`

### 🍽️ [SpinNSpice](https://github.com/moeezmalik10/SpinNSpice)
