## 🚀 Featured Projects

### 🧠 [Face Recognition System](https://github.com/moeezmalik10/recognition-system)
A from-scratch face recognition system built with a **NumPy-only multilayer perceptron** — no deep learning frameworks, just linear algebra and gradient descent, implemented by hand.

`Python` `NumPy` `Jupyter Notebook`

---

### 🏥 [Alzheimer's Disease Detection using MRI Images](https://github.com/moeezmalik10/Alzheimer-s-Disease-Detection-using-MRI-Images)
A deep learning pipeline that classifies Alzheimer's disease stages from brain MRI scans using a fine-tuned **ResNet-18** convolutional network — extended with Grad-CAM explainability research.

`Python` `ResNet-18` `Computer Vision`

---

### 🗺️ [The Living Archive](https://github.com/moeezmalik10/the-living-archive)
A platform for documenting discoveries and urban exploration — built for explorers to log, tag, and share findings from abandoned places and hidden spots.

`TypeScript` `Web App` · [🔗 Live Demo](https://the-living-archive-neon.vercel.app)

---

### 🧭 [DirectionWise](https://github.com/moeezmalik10/directionwise)
An AI-powered career-counselling tool that helps students explore paths and make informed decisions about their future.

`Python` `Streamlit` · [🔗 Live Demo](https://directionwise-jx2y43b9mxn9rtbnhgmqcw.streamlit.app/)
